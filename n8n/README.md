# ระบบถามตอบอัตโนมัติ LINE OA + AI Agent

ระบบแชทบอทของ **บริษัท ไอว่า ริช ยู ดี จำกัด** บน n8n ที่ตอบคำถามลูกค้าทาง LINE OA
โดยดึงคำตอบจาก Google Sheets และมี **AI Agent** ช่วยตอบคำถามที่นอกเหนือจาก FAQ
พร้อมระบบ **จับคำที่พิมพ์ผิด** สำหรับภาษาไทยโดยเฉพาะ

> ⚠️ **สำคัญ — ต้องทำก่อนใช้งาน**
> ไฟล์ workflow เดิม (`n8n_Line_oa.json`) มี **LINE Channel Access Token ฝังอยู่ในไฟล์** ซึ่งหลุดออกไปแล้ว
> กรุณาเข้า [LINE Developers Console](https://developers.line.biz/console/) แล้ว **Revoke/ออก token ใหม่** ทันที
> เวอร์ชันนี้เก็บ token ไว้ใน Credential ของ n8n ไม่มีอยู่ในไฟล์ JSON อีกต่อไป

## สิ่งที่เพิ่มขึ้นจากของเดิม

| หัวข้อ | ของเดิม | เวอร์ชันนี้ |
|---|---|---|
| อ่านข้อความจาก LINE | อ่าน `body.message` (LINE ไม่ได้ส่งมาแบบนี้) | อ่าน `body.events[]` ตามสเปกจริงของ LINE |
| จับคู่คำถาม | ตรงทุกตัวอักษร หรือ `includes()` เท่านั้น | ยุบวรรณยุกต์/สระ/พยัญชนะ + Levenshtein + Dice bigram + โครงพยัญชนะ + แก้เคสลืมสลับภาษา |
| คำถามนอก FAQ | ตอบ "ขออภัย ยังไม่พบข้อมูล" | **AI Agent** ตอบได้ทุกเรื่องในธุรกิจ จากข้อมูลบริษัท + FAQ + คลังความรู้ |
| ถามต่อเนื่อง | ไม่ได้ | จำบทสนทนาแยกตาม userId (เช่น "แล้วราคาล่ะ") |
| เจอหลายหัวข้อ | โยนรายการกลับให้ลูกค้าเลือกเอง | AI เลือกให้ + มีปุ่ม Quick Reply |
| สติกเกอร์ / เพิ่มเพื่อนใหม่ | ไม่รองรับ (พัง) | มีข้อความต้อนรับและข้อความแนะนำ |
| Token | ฝังในไฟล์ JSON | เก็บใน Credential ของ n8n |
| คำตอบยาว / Markdown | ส่งดิบ ๆ (LINE แสดงผลเพี้ยน) | ล้าง Markdown + ตัดเป็นหลายข้อความอัตโนมัติ |
| AI/ระบบล่ม | ลูกค้าไม่ได้รับคำตอบ | มีข้อความสำรองพร้อมเบอร์ติดต่อเสมอ |
| LINE ส่งหลายข้อความมาพร้อมกัน | ตอบแค่ข้อความแรก | ตอบครบทุกข้อความ ไม่สลับคน |
| ข้อมูลที่ส่งให้ AI | – | เรียง FAQ + คลังความรู้ **ตามความเกี่ยวข้องกับคำถามนั้น** เรื่องที่ตรงประเด็นที่สุดอยู่ต้นเสมอ |

## ตัวอย่างการจับคำที่พิมพ์ผิด

ทดสอบจริงด้วย `node test/run-tests.mjs` (ผ่าน 44/44):

| ลูกค้าพิมพ์ | ระบบเข้าใจว่า | ความมั่นใจ |
|---|---|---|
| `ราคะ` | ราคา | 100% |
| `ร่าคา` / `ราค่า` | ราคา | 100% |
| `ลาคา` / `ราฆา` | ราคา | 100% |
| `ราคาาาา` | ราคา | 97% |
| `สมัคเรียน` / `สมักรเรียน` | สมัครเรียน | 93% |
| `ทดลองเรีบน` | ทดลองเรียน | 93% |
| `ik8k` (ลืมสลับภาษา) | ราคา | 100% |
| `ทu8k` (สลับภาษากลางคัน) | ราคา | 100% |
| `อยากทราบราคะของสื่อปฐมวัยครับ` | ราคา | 97% |
| `พารา` | ระบบเดาไม่ชัด → ส่งให้ AI พร้อมบอกว่า "ราคา" น่าจะใช่ที่สุด | 50% |

**หลักการทำงาน 4 ชั้น**

1. **ยุบเสียง (fold)** — ตัดวรรณยุกต์ ไม้ไต่คู้ ทัณฑฆาต แล้วยุบตัวอักษรที่เสียงเดียวกันเป็นตัวแทนเดียว
   (`ข ฃ ค ฅ ฆ`→`ค`, `ร ล ฬ`→`ร`, `ะ ั า ๅ ำ`→`า`, `ิ ี`→`ี` ฯลฯ)
2. **วัดความคล้าย** — Levenshtein + Dice bigram + หา "หน้าต่าง" ที่คล้ายที่สุดในประโยคยาว
3. **โครงพยัญชนะ** — ถอดสระทิ้ง เทียบเฉพาะพยัญชนะ จับคำที่สระเพี้ยนทั้งคำ
4. **แป้นพิมพ์เกษมณี** — แปลงข้อความที่พิมพ์ด้วยแป้นอังกฤษกลับเป็นไทย

ถ้าทั้ง 4 ชั้นยังไม่มั่นใจ → ส่งต่อให้ AI Agent พร้อมรายการหัวข้อที่ใกล้เคียงและเปอร์เซ็นต์ความมั่นใจ
AI จะเดาเจตนาลูกค้าเองอีกชั้นหนึ่ง จึงแทบไม่มีทางตอบว่า "ไม่เข้าใจ"

**ทำไมถึงตอบตรงประเด็น**

ทุกครั้งที่ส่งให้ AI ระบบจะจัดอันดับ FAQ และคลังความรู้ใหม่ตามความเกี่ยวข้องกับคำถามนั้น ๆ
เรื่องที่ตรงประเด็นที่สุดจึงอยู่บรรทัดแรกของ prompt เสมอ และไม่มีทางถูกตัดทิ้งแม้ชีตจะยาวหลายร้อยแถว
พร้อมกำกับกติกาไว้ว่าให้ตอบเฉพาะที่ถาม ห้ามแถมข้อมูลที่ไม่เกี่ยว ถ้าถามหลายเรื่องให้ตอบครบทุกเรื่อง
และถ้าตอบได้แค่บางส่วนให้บอกตรง ๆ แล้วส่งต่อให้ทีมงาน

## ลำดับการทำงาน

```
Webhook (LINE)
   └─ Get FAQ ────────► Get Knowledge ────────► Parse LINE Event
                                                     ├─► Show Typing  (แสดง "กำลังพิมพ์" — ทางตัน ล้มเหลวได้)
                                                     └─► Smart Thai Matcher
                                                              └─► มั่นใจพอไหม?
                                                                   ├─ ใช่ ──────────────► Build LINE Reply
                                                                   └─ ไม่ ─► AI Agent ──► Build LINE Reply
                                                                                              └─► Reply to LINE ─► Log to Sheet
```

ดึงข้อมูลจากชีตก่อนแล้วค่อยแตกเป็นรายข้อความ ทำให้อ่านชีตครั้งเดียวต่อ 1 request
และตอบได้ครบทุกข้อความแม้ LINE ส่งหลาย event มาพร้อมกัน

## วิธีติดตั้ง (7 ขั้นตอน)

### 1. เตรียม Google Sheets

ในไฟล์ `Line OA and n8n` เดิม สร้าง/แก้ชีตดังนี้

**ชีต `FAQ`** (มีอยู่แล้ว) — คอลัมน์ `keyword`, `answer`
ใส่หลายคำในช่อง `keyword` เดียวได้ คั่นด้วย `,` หรือ `|`
เช่น `ราคา, ค่าใช้จ่าย, กี่บาท, เท่าไหร่` → ลูกค้าพิมพ์คำไหนก็เจอ

**ชีต `Knowledge`** (สร้างใหม่) — คอลัมน์ `topic`, `content`
ใส่เรื่องอะไรก็ได้ที่อยากให้บอทตอบได้ เช่น เงื่อนไขการรับประกัน ขั้นตอนสั่งซื้อ พื้นที่ให้บริการ
ชีตนี้ไม่ต้องมีคีย์เวิร์ด AI จะหยิบไปใช้เอง (ถ้ายังไม่สร้าง ระบบก็ยังทำงานได้ปกติ)

**ชีต `Chat Log`** (ไม่บังคับ) — คอลัมน์ `timestamp`, `userId`, `question`, `route`, `matchType`, `matchedKeyword`, `score`, `answer`
สร้างแล้วค่อยเปิดใช้งานโหนด `Log to Sheet` ใน n8n เพื่อเก็บสถิติว่าลูกค้าถามอะไรบ้าง

> ใช้ไฟล์ใน `templates/` นำเข้าเป็นชีตได้เลย (File → Import → Upload)

### 2. แก้ข้อมูลบริษัท

เปิด `src/business-profile.txt` แก้ราคา บริการ เบอร์โทร ให้เป็นข้อมูลจริงล่าสุด
แล้วรัน `node build.mjs` เพื่อสร้างไฟล์ JSON ใหม่

### 3. Import เข้า n8n

n8n → **Workflows** → **Import from File** → เลือก `line-oa-ai-agent.json`

### 4. สร้าง Credential ของ LINE

n8n → **Credentials** → **New** → **Header Auth**

| ช่อง | ค่า |
|---|---|
| Name | `LINE Channel Access Token` |
| Header Name | `Authorization` |
| Header Value | `Bearer <token ใหม่ของคุณ>` |

จากนั้นเลือก credential นี้ในโหนด **Reply to LINE** และ **Show Typing**

### 5. ใส่ Credential ของ AI

โหนด **OpenAI Chat Model** → เลือก/สร้าง OpenAI API credential (ค่าเริ่มต้นใช้โมเดล `gpt-4.1-mini`)

อยากใช้ Google Gemini แทน: ลบโหนด OpenAI Chat Model ออก แล้วลาก **Google Gemini Chat Model**
มาต่อเข้าช่อง **Chat Model** ใต้โหนด AI Agent (ที่เหลือทำงานเหมือนเดิมทุกอย่าง)

### 6. ตั้งค่า Webhook ใน LINE

URL ของ webhook ยังเป็นเส้นทางเดิม (`/webhook/lineoa_chatbot`) จึงไม่ต้องแก้ที่ฝั่ง LINE
ใน LINE Developers Console ให้เปิด **Use webhook** และปิด **Auto-reply messages** กับ **Greeting messages**

### 7. Activate

กด **Active** ที่มุมขวาบนของ workflow แล้วทดลองทักบอทใน LINE

## การปรับจูน

แก้ค่าคงที่ด้านบนของ `src/smart-matcher.js` แล้วรัน `node build.mjs` ใหม่

| ค่า | ค่าเริ่มต้น | ความหมาย |
|---|---|---|
| `DIRECT_THRESHOLD` | `0.90` | ความมั่นใจขั้นต่ำที่จะตอบจาก Sheet ทันทีโดยไม่เรียก AI<br>ตั้ง `2` = ให้ AI ตอบทุกครั้ง (ฉลาดสุด แต่ค่า token สูงและช้ากว่า)<br>ตั้ง `0.75` = ประหยัดสุด แต่เสี่ยงตอบผิดหัวข้อ |
| `CANDIDATE_THRESHOLD` | `0.35` | คะแนนขั้นต่ำที่จะถูกเสนอเป็น "ตัวเลือกที่น่าจะใช่" ให้ AI |
| `SHORT_QUERY_SLACK` | `8` | คำถามที่ยาวกว่าคีย์เวิร์ดเกินค่านี้ ถือเป็นประโยค → ส่งให้ AI ตอบ<br>(เช่น "ขอใบเสนอราคาโรงเรียน 40 เครื่อง" ไม่ควรตอบด้วย FAQ "ราคา" สั้น ๆ) |
| `HONORIFIC` | `'ครับ'` | คำลงท้ายของบอท เปลี่ยนเป็น `'ค่ะ'` ได้ |
| `MAX_FAQ_IN_PROMPT` | `60` | จำนวนแถว FAQ สูงสุดที่ส่งเข้า prompt (เรียงตามความเกี่ยวข้องก่อนตัด) |
| `MAX_KNOWLEDGE_IN_PROMPT` | `30` | จำนวนแถวคลังความรู้สูงสุดที่ส่งเข้า prompt (เรียงตามความเกี่ยวข้องก่อนตัด) |

**อยากเปลี่ยนบุคลิก/กติกาการตอบของ AI** → แก้ส่วน `systemPrompt` ท้ายไฟล์ `src/smart-matcher.js`

## ข้อควรรู้เรื่องค่าใช้จ่ายและความเร็ว

- คำถามที่ตรง FAQ (คะแนน ≥ 90% และเป็นคำสั้น) จะ **ไม่เรียก AI เลย** ตอบภายในไม่ถึง 1 วินาที
- คำถามอื่นเรียก AI ประมาณ 1,500-2,500 token ต่อครั้ง (system prompt บรรจุ FAQ ทั้งหมด)
  ถ้า FAQ ยาวมากจนเปลืองเกินไป ให้ลด `MAX_FAQ_IN_PROMPT` หรือ `MAX_ANSWER_CHARS`
- โหนด **Show Typing** ทำให้ LINE แสดง "กำลังพิมพ์..." ระหว่างรอ AI (ใช้ได้เฉพาะแชท 1:1)
- `replyToken` ของ LINE มีอายุจำกัด ถ้า AI ตอบช้ากว่านั้นจะส่งไม่สำเร็จ — ถ้าเจอบ่อย ให้ลด `maxTokens`
  ที่โหนด OpenAI Chat Model หรือเปลี่ยนไปใช้โมเดลที่เร็วกว่า
