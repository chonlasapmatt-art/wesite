# LINE OA + AI Agent — เวอร์ชันพื้นฐาน

ผังเดียวจบ 5 โหนด ตามที่ต้องการ

```
Webhook ─► Get row(s) in sheet ─► เตรียมข้อมูลให้ AI ─► AI Agent ─► ตอบกลับ LINE
                (ชีต FAQ)                                  ▲
                                                    OpenAI Chat Model
```

ใช้ไฟล์ **`line-oa-simple.json`** ไฟล์เดียว — Import เข้า n8n ได้เลย

---

## เริ่มใช้งาน 3 ขั้นตอน

1. Import `line-oa-simple.json` เข้า n8n
2. โหนด **ตอบกลับ LINE** → ช่อง `Authorization` วาง `Bearer <token ใหม่>`
   (token เดิมในไฟล์เก่าหลุดแล้ว ต้องออกใหม่ที่ LINE Developers Console)
3. โหนด **OpenAI Chat Model** → ใส่ API key แล้วกด **Active**

Google Sheets credential กับ URL ของ webhook เป็นตัวเดิม ไม่ต้องแก้อะไร

---

## ใช้ชีตเดียว

ชีต **`FAQ`** คอลัมน์ `keyword` กับ `answer` เท่านั้น

| keyword | answer |
|---|---|
| `ราคา, ค่าใช้จ่าย, กี่บาท` | สื่อการเรียนรู้เริ่มต้น 2,200 บาท ราคาจริงขึ้นกับจำนวนสิทธิ์ใช้งาน |
| `เวลาทำการ` | จันทร์-ศุกร์ 08:30-17:30 น. |

- ช่อง `keyword` ใส่หลายคำได้ คั่นด้วย `,` ลูกค้าพิมพ์คำไหนก็เจอ
- **อยากให้บอทตอบเรื่องอะไรเพิ่ม = เพิ่มแถวในชีต** ไม่ต้องแก้ workflow
- ทุกแถวในชีตถูกส่งให้ AI ทั้งหมด AI จึงตอบข้ามเรื่องและรวบหลายแถวมาตอบในครั้งเดียวได้

---

## AI ตอบยังไง

ทุกคำถามส่งให้ AI ตอบเสมอ โดยก่อนส่ง ระบบจะเรียงแถวในชีตตามความใกล้เคียงกับคำถามนั้น
และบอก AI ไปด้วยว่า "ระบบเดาว่าน่าจะหมายถึงเรื่องนี้" — จับคำที่พิมพ์ผิดได้โดยตัดวรรณยุกต์ทิ้ง
แล้วยุบตัวอักษรเสียงเดียวกันเป็นตัวเดียว

`ราคะ` `ร่าคา` `ลาคา` `ราคาาาา` `ขอทราบราคาหน่อยครับ` → เจอ **ราคา** หมด

คำสั่งที่ให้ AI เน้นว่า **ตอบให้จบในข้อความเดียว ไม่ต้องรอทีมงานติดต่อกลับ**
จะแจ้งเบอร์โทรก็ต่อเมื่อเป็นเรื่องที่ต้องตกลงรายบุคคลจริง ๆ เช่น ต่อรองราคา หรือนัดวันเวลา

## แก้ข้อความ/บุคลิกของบอท

เปิดโหนด **เตรียมข้อมูลให้ AI** แก้ได้ 2 จุดบนสุดของโค้ด

- `BUSINESS` — ข้อมูลบริษัท ที่อยู่ เบอร์โทร
- `HONORIFIC` — คำลงท้าย `'ครับ'` หรือ `'ค่ะ'`

ส่วนกติกาการตอบอยู่ใต้คำว่า `กติกาการตอบ:` ท้ายโค้ด แก้เป็นภาษาคนได้เลย
